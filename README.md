# BedBrick-Auth

Static website for the BedBrick Minecraft authentication server. Makes registration and login easier than using curl.

## ⚠️ Server warning

This site is **only a client**. It sends your data to whichever server you pick in the host selector.

**Before entering your password:**
- Trust the server — its owner sees everything you send.
- Use `https://` only. `http://` is insecure.

**Don't:**
- Use your main password (email, bank, etc.).
- Trust unknown hosts.
- Reuse passwords across servers.

The site does not verify servers. If you add a bad one — your data goes there. Author is not responsible for third-party servers.

## Features

- Email registration + verification
- Login by email
- One-time code for the Minecraft launcher
- Host selector

## Stack

Plain HTML/CSS/JS. Hosted on GitHub Pages.
